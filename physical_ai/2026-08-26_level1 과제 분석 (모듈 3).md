### 벡터 연산 모듈 (`src/vectors.py`)

- `as_vector`
	- 모든 함수의 진입점에서 `np.asarray(v, dtype=float)` 후 `ndim == 1` 체크
	- 1차원이 아니면 `ValueError` → 다른 함수에서 shape 신경 쓰지 않고 벡터 연산 가능

- `angle_between`
	- `cos = a·b / (‖a‖‖b‖)` 계산 후 `arccos` 적용
	- 부동소수점 오차로 `cos`가 `[-1, 1]` 범위를 살짝 벗어나면 `arccos`가 `nan`을 반환
		→ **`np.clip(cos, -1, 1)`로 도메인 강제**

| 함수                    | 역할            | 비고                              |
| :-------------------- | :------------ | :------------------------------ |
| `dot(a, b)`           | 내적            | for문으로 구현함                      |
| `norm(v)`             | 벡터 크기         | `sqrt(sum(v**2))`               |
| `angle_between(a, b)` | 사이각           | `np.clip` 필수 ⭐                  |
| `cross(a, b)`         | 외적            | 3차원 벡터만 허용, 길이 체크 후 `TypeError` |
| `normalize(v)`        | 단위벡터화         | `eps=1e-12` 기준으로 영벡터 거르기        |
| `project(a, b)`       | a를 b 방향으로 정사영 | `(a·b / b·b) * b`               |
| `reject(a, b)`        | 정사영의 나머지 성분   | `a - project(a, b)`             |
| `skew(v)`             | 반대칭행렬         | `skew(a) @ b == cross(a, b)` 검증 |

- **정사영**
	- `project(a, b)`는 `b` 방향 성분, `reject(a, b) = a - project(a, b)`는 `b`에 수직인 나머지 성분
	- 과제 요구사항: 
		1) `reject(a,b)`가 `b`와 수직인지 (`dot(reject, b) = 0`) 
		2) `project + reject == a` 인가

```python
# skew(a) @ b 와 cross(a, b) 일치 검증
def skew(v) -> np.ndarray:
    v = as_vector(v)
    if len(v) != 3:
        raise ValueError(f"벡터의 길이가 3이 아닙니다. 현재 벡터의 길이: {len(v)}")
    return np.array([[0, -v[2], v[1]],
                      [v[2], 0, -v[0]],
                      [-v[1], v[0], 0]])

# skew(a).T == -skew(a) 여야 반대칭행렬
```

- **에러 처리**
	- 영벡터 정규화, 크기가 0인 벡터로 정사영 → `eps=1e-12` 기준으로 `ValueError` raise
	- `cross`는 길이가 3이 아니면 `TypeError`, 나머지 길이 불일치는 `ValueError`로 구분해서 사용
