#### ROS2 그래프 확인 명령어

```
ros2 node list    #실행 중인 노드 목록
ros2 topic list    # 토픽 목록
ros2 topic echo /scan    # 토필 메시지 실시간 출력
ros2 topic hz /scan    # 발행 주파수 측정
rqt_graph    # 노드-토픽 연결 시각화
```


#### SLAM으로 지도 만들기 (Gazebo + Cartographer)
-  Gazebo에서 turtlebot3_world 로드
- Cartographer 노드 + RViz 켜서 LaserScan 기반으로 SLAM 진행
- teleop_keyboard로 로봇 돌려보면서 map 채운 후, 완성된 맵 저장
```
export TURTLEBOT3_MODEL=burger
ros2 launch turtlebot3_gazebo turtlebot3_world.launch.py
ros2 launch turtlebot3_cartographer cartographer.launch.py use_sim_time:=True
ros2 run turtlebot3_teleop teleop_keyboard
ros2 run nav2_map_server map_saver_cli -f ~/map
```


#### Navigation2로 자율주행
- 저장한 map.yaml불러와서 navigation2launch
- RViz에서 `2D Pose Estimate`로 초기 위치 잡고, Nav2 Goals로 목표 찍기
```
ros2 launch turtlebot3_navigation2 navigation2.launch.py map:=~/map.yaml use_sim_time:=True
```
