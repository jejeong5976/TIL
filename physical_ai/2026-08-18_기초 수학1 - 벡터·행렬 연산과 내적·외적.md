### [17강] 벡터·행렬 연산과 내적·외적

- **기저 (Basis)**
	- 로봇의 base·camera·LiDAR 좌표계는 각각 서로 다른 기저(basis)를 고른 것
	- 좌표 변환 = 한 기저에서 잰 숫자를 다른 기저의 숫자로 바꾸는 일

- **행렬 곱**
	- `Ax`는 A의 열벡터들을 x의 성분만큼 섞은 선형결합
	- `AB` = B를 먼저 적용하고 A를 적용하는 합성 변환이 되도록 정의된 것
		- `A(Bx) = (AB)x`
	- 결합법칙 성립: `(AB)C = A(BC)`
	- 분배법칙 성립: `A(B+C)=AB+AC` 
	- 교환법칙 성립 X: `AB ≠ BA` ("전단 후 반사" ≠ "반사 후 전단") ⭐
	- 행렬 곱 조건: 앞 행렬 열 개수 = 뒤 행렬 행 개수, `(m×n) @ (n×p) → (m×p)`
		- numpy shape 오류 대부분 이 조건을 맞추지않아서 발생하는 것


- **행렬 4가지**

| 행렬       | 정의      | 특징                                    |
| -------- | ------- | ------------------------------------- |
| 단위행렬 I   | AI=IA=A | 주대각행렬만 1, 나머진 0                       |
| 전치 행렬 Aᵀ | 행·열 맞바꿈 | (AB)ᵀ = BᵀAᵀ                          |
| 대칭 행렬    | A = Aᵀ  | 관성 텐서, 강성행렬, 공분산 행렬                   |
| 반대칭      | A = -Aᵀ | 대각 성분 0, 주대각 행렬 기준 부호만 반대, 외적·각속도의 형태 |
	- 정방행렬 분해: `A = ½(A+Aᵀ) + ½(A-Aᵀ)` (대칭 + 반대칭)


- **외적 = 반대칭행렬 곱** ⭐
	- `a × b = [a]ₓ b`
	```
	# 반대칭 행렬
	[a]ₓ = |  0  -a3  a2 |
	       |  a3  0  -a1 |
	       | -a2  a1  0  |
	```
	- 직접 b랑 곱해서 증명해봄
		- `[a]ₓ b = (a2b3-a3b2, a3b1-a1b3, a1b2-a2b1)` → i,j,k 행렬식으로 계산한 외적 값이랑 동일함 확인
	- 로봇공학 핵심 관계식: `Ṙ = [ω]ₓ R` (강체 각속도 ↔ 회전행렬의 시간 미분)
	- 22강 로드리게스 공식의 K 행렬이 이 `[n]ₓ` 형태라고 함 (지금은 구조만)


- **내적**
	- `a · b = axbx + ayby + azbz = |a||b| cos θ`
	- 두 벡터 사이 각도: `cos θ = (a·b) / (|a||b|)`
	- 정사영(projection 계산) 
		`proj_b(a) = ((a·b)/(b·b))*b`
	- 수직 판정: `a·b = 0` → 직교
	- projection과 각도 계산에 쓰임
		- 로봇의 진행방향과 목표 방향의 차이 값으로 피드백 받아 수정


- **외적**
	- `a × b = (aybz-azby, azbx-axbz, axby-aybx)`, `|a×b| = |a||b| sin θ`
	- 방향: 오른손 법칙 (a에서 b로 손 감을 때 엄지 방향)
	- 평면 법선, 두 자세 사이 회전축, 좌표축 생성(세번째 축), 넓이/방향 판정


- **내적 vs 외적 비교**

| 구분       | 내적             | 외적             |
| -------- | -------------- | -------------- |
| 결과       | 스칼라            | 벡터             |
| 크기       | \|a\|\|b\|cosθ | \|a\|\|b\|sinθ |
| 0이 되는 조건 | 두 벡터 수직        | 두 벡터 평행        |
| 교환       | a·b = b·a      | a×b = -(b×a)   |
| 로봇에서     | 각도·정렬 판단       | 법선·회전축·각속도     |


- **선형독립과 rank**
	- 선형독립: `c1v1+...+ckvk=0`을 만족하는 유일한 해가 `c1=...=ck=0`뿐인 경우
	- rank(A) = 선형독립인 행(또는 열)의 최대 개수, 가우스 소거 후 0 아닌 행 개수로 계산
	- rank와 `Ax=b` 해의 존재성

| 조건 | 결과 |
|---|---|
| rank A < rank[A\|b] | 해 없음 |
| rank A = rank[A\|b] = n | 유일해 |
| rank A = rank[A\|b] < n | 무수히 많은 해 (자유변수 n-rank개) |

	- 차원 정리: `rank(A) + dim N(A) = n` → 독립 정보 개수 + 자유도 = 전체 미지수
	- 예시: GPS는 위치3+시계오차1=미지수 4개라 위성 4개 필요, 로봇팔 관절 6개여도 특이점에서 자코비안 rank 5면 실제 자유도는 5
