### [20강] 쿼터니언과 SLERP 보간_그리고_고유값 문제 (고유값과 고유벡터부터~)

#### 고유값과 고유벡터

-  고유벡터(eigenvector): 행렬 A를 곱해도 **방향은 그대로**, **길이만 λ배**인 특별한 벡터 v
- 고유값(eigenvalue): 그 배율 λ

```
Av = λv        (v ≠ 0)
```

| 기호  | 의미                |
| --- | ----------------- |
| A   | 정방행렬 (변환)         |
| v   | 고유벡터 - 변환해도 방향 유지 |
| λ   | 고유값 - 그 방향 배율     |

**특성방정식 (λ 구하는 법)**
- `Av=λv` → `(A-λI)v=0`
- v가 영벡터가 아니려면 `(A-λI)`가 특이행렬 → 역행렬 없음 ⭐
	- 특이행렬(singular matrix) : 역행렬이 존재하지 않는 정방행렬

```
det(A - λI) = 0
```

- `(A-λI)v=0`에서 원하는 건 v≠0인 해
	- 만약 `(A-λI)`가 정상 행렬(det≠0, 역행렬 있음)이라면, 양변에 역행렬을 곱해서 `v = (A-λI)⁻¹·0 = 0`
	- v≠0인 진짜 해가 존재하려면 `(A-λI)`가 반드시 특이행렬(det=0)이어야 함
		→ 그래야 어떤 방향을 "0으로 눌러버려서" 그 방향의 벡터(고유벡터)가 통과할 틈이 생김
- 그래서 `det(A-λI)=0`을 만족하는 λ들 = **고유값**


#### 회전행렬

- 회전행렬의 고유벡터 → 회전축
- 3차원 회전행렬 R의 고유값은 항상:

```
λ₁ = 1                    (실수)
λ₂, λ₃ = cos θ ± i sin θ   (켤레복소수)
```

| 항목       | 의미                                           |
| -------- | -------------------------------------------- |
| λ=1 고유벡터 | `R·n = n` → 회전시켜도 안 움직임 → **회전축 n**          |
| 회전각      | `tr R = 1 + 2cosθ` → `θ = arccos((trR-1)/2)` |

**보충: 실습 5, 6번**

```
Rz(90°) = [ 0  -1  0 ]
          [ 1   0  0 ]
          [ 0   0  1 ]
```

| 확인 | 결과 |
|---|---|
| (0,0,1)에 곱하면 | 그대로 (0,0,1) → λ=1 고유벡터 = z축 ⭐ |
| tr R | 0+0+1=1 → `1=1+2cosθ` → `θ=90°` ✓ |
→ 회전행렬 → 고유값 문제 → 축(λ=1 고유벡터)+각(trace) → **쿼터니언의 (n,θ)** ⭐


#### 대각화

- n x n 행렬A가 n개의 **선형독립 고유벡터**를 가지면:

```
A = P Λ P⁻¹
```

| 기호 | 의미 |
|---|---|
| P | 고유벡터들을 열로 쌓은 행렬 |
| Λ | 대각선에 고유값만 있는 행렬 |

- 활용: `Aᵏ = P Λᵏ P⁻¹` → A를 k번 곱하는 대신 **대각원소만 k제곱** (마르코프 연쇄, 피보나치)


**보충 — 실습 4번 A로 확인**

```
P = [ 1   1 ]      Λ = [ 5  0 ]
    [ 1  -2 ]          [ 0  2 ]

A⁵ = P · diag(5⁵, 2⁵) · P⁻¹ = P · diag(3125, 32) · P⁻¹
```

- 대각화 안 되는 경우 ⭐ 

| 단계    | 내용                                   |
| ----- | ------------------------------------ |
| 특성방정식 | `(2-λ)²=0` → λ=2 (중복)                |
| 고유벡터  | `(2-2)x+y=0 → y=0` → v=(1,0) **1개뿐** |
| 결론    | 2×2인데 독립 고유벡터 1개 → P 못 만듦 → 대각화 불가능  |


#### 대칭행렬

**스펙트럼 정리**
- `A=Aᵀ`이면 항상 성립

| 성질               | 의미                    |
| ---------------- | --------------------- |
| 1. 고유값 전부 실수     | 복소수 걱정 없음             |
| 2. 고유벡터끼리 직교     | 축이 90°로 갈라짐           |
| 3. `A=QΛQᵀ`로 대각화 | `Q⁻¹=Qᵀ` → 역행렬 계산 불필요 |
- 모든 고유값이 양수 ⟺ 양의 정부호(positive definite) ⟺ 모든 x =! 0 에 대해 `xᵀAx>0`
- 공학의 행렬은 대부분 대칭임
	- 공분산 행렬 (PCA) - 고유벡터: 데이터가 퍼진 주방향, 고유값: 그 방향의 분산
		- **물체 자세 추정의 원리**: 점군의 공분산행렬을 고유 분해하면 물체의 주축(자세)이 나옴
	- 강성 행렬 - 고유벡터: 진동모드 형상, 고유값: 고유진동수의 제곱
	- 관성 텐서 - 고유벡터: 관성 주축, 고유값: 주관성모멘트
	- 응력 텐서 - 고유벡터: 주응력 방향, 고유값: 주응력 크기

- NumPy - 대칭행렬에서는 대칭전용 함수를 씀
	- `np.linalg.eig` X, `np.linalg.eigh` 사용
		- 더 빠르고, 실수 고유값을 보장, 고유벡터의 직교성이 수치적으로 정확하기 때문 


#### 특이값 분해 (SVD)

```
A = U Σ Vᵀ       (U, V: 직교행렬, Σ: 대각)
```

- 정방·대칭이 아니어도 분해 가능 = 스펙트럼 정리의 일반화
- 임의의 m×n 행렬 → **회전(Vᵀ) → 축별 신축(Σ) → 회전(U)** 로 분해됨
- 특이값 σᵢ = `AᵀA`의 고유값의 제곱근 ⭐ 
- 큰 σᵢ 몇 개만 남기면 → 저계수 근사

**쓰이는 곳**

| 용도             | 강의 연결             |
| -------------- | ----------------- |
| 두 점군 사이 최적 회전  | Kabsch 알고리즘       |
| 이미지 압축·노이즈 제거  | 작은 특이값 버리기        |
| 로봇 자코비안 조작성 분석 | 특이값→0 = 특이점(18강)  |
| 최소자승 안정적 해법    | `np.linalg.lstsq` |

## 알게 된 것

- `Av=λv` = 변환이 방향을 못 건드리는 특별한 방향 찾기
	- `det(A-λI)=0`으로 λ 계산, 대각합·행렬식으로 항상 검산

- 쿼터니언(축,각) = 회전행렬의 λ=1 고유벡터가 회전축, `trR=1+2cosθ`가 회전각 ⭐

- 대각화 = 고유벡터 기저로 좌표계 이동 → 행렬이 대각행렬로 단순화. 
	- 단, 중복 고유값에 독립 고유벡터가 부족하면 대각화 불가능

- 대칭행렬: 고유값 실수 + 고유벡터 직교 + `Q⁻¹=Qᵀ`
	→ 응력·관성·강성·공분산 행렬이 전부 대칭이라 공학에 계속 등장

- SVD = 대칭행렬 스펙트럼 정리의 일반화, 정방·대칭 아니어도 분해 가능
