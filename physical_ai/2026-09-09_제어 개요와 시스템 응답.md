### [Lv2 1강] 제어 개요와 시스템 응답

#### 개루프 vs 폐루프

- **개루프(open-loop)**
	- 목표값 → 제어기 → 시스템으로 신호가 한 방향으로만 흐름
	- 설계값대로 작동하도록 하며 피드백을 하지 않음 (출력 확인 X)
- **폐루프(closed-loop, 피드백)**
	- 센서가 출력을 측정해서 입력 쪽으로 되먹임
	- 오차 `e = r - y`를 제어기가 계속 보정

- IMU 센서의 경우 통상적으로 피드백 주기가 60Hz~120Hz 대역인 경우가 많다고 함

| 구분       | 개루프                 | 폐루프                  |
| -------- | ------------------- | -------------------- |
| 센서       | 불필요 → 저렴·단순         | 필요 → 비용·복잡도 증가       |
| 외란 대응    | 불가 — 오차 그대로 남음      | 자동 보정                |
| 모델 오차 대응 | 불가 — 모델 틀리면 결과도 틀림  | 자동 보정                |
| 안정성 문제   | 없음 (시스템 자체가 안정하면)   | 잘못 설계하면 발진·불안정       |
| 대표 예     | 토스터, 세탁기 타이머, 스텝 모터 | 에어컨, 서보 모터, 드론 자세 제어 |

#### 전달함수

- 제어기 설계하려면 먼저 플랜트가 입력에 어떻게 반응하는지 알아야 함 → 물리 법칙 세우면 미분방정식 나옴
- 미분방정식은 다루기 번거로우므로 **라플라스 변환**으로 대수식으로 바꿈 (미분 `d/dt` → `s` 곱하기)
- 입력의 라플라스 변환 대비 출력의 라플라스 변환의 비 = **전달함수 G(s)**
- 전달함수는 시스템의 "명함" — 모양이 같으면 전기 모터든 방 온도든 물탱크든 반응 패턴이 동일함
- 그래서 대표 패턴 두 가지(1차·2차)만 깊이 익히면 됨

공식 유도(라플라스 변환 과정, `Js + b` 등)는 오늘은 스킵, 다음에 직접 유도해보기로 함

#### 1차 시스템 — 시정수 τ
- **현상**: 모터에 PWM 계단 입력 주면 속도가 목표로 바로 점프하지 않고, 처음엔 빠르게 오르다 점점 완만해지며 수렴함
- **직관**: 목표까지 남은 거리에 비례해서 접근 → 남은 거리 절반되면 접근 속도도 절반 → 지수 곡선

```
G(s) = K / (τs + 1)
```

| 기호  | 의미                                        |
| --- | ----------------------------------------- |
| K   | 정상상태 이득(DC gain) - 입력 1을 오래 유지했을 때 최종 도달값 |
| τ   | 시정수(time constant) - 반응의 빠르기(시간 단위)       |

- step input을 주면 출력은 지수적으로 목표에 접근: `y(t) = K(1 - e^(-t/τ))`

#### 2차 시스템 — 오버슈트와 정착시간

ex) 로봇팔 관절에 "90°로 가라" 명령 시 어떤 게인에서는 95°까지 갔다가 되돌아오고 몇 번 출렁인 뒤 멈춤 (1차에서는 없던 현상)

```
G(s) = ωn² / (s² + 2ζωn·s + ωn²)
```

| 기호     | 의미                                    |
| ------ | ------------------------------------- |
| ωn     | 고유 진동수(natural frequency) — 진동의 빠르기   |
| ζ (제타) | 감쇠비(damping ratio) — 진동이 얼마나 빨리 잦아드는가 |

- `ζ = 0`: 영원히 진동 / `ζ = 0`: 진동 없이 가장 빠르게 도달(임계 감쇠) / `ζ > 1`: 느릿하게 접근 (과감쇠)


 **시간응답을 읽는 4가지 지표**

| 지표               | 정의                             | 의미               |
| ---------------- | ------------------------------ | ---------------- |
| 상승시간 $t_r$       | 최종값 10%→90% 도달 시간              | 반응의 민첩함          |
| 오버슈트 $M_p$       | 최댓값이 최종값 초과한 비율(%)             | 지나침의 정도          |
| 정착시간 $t_s$       | 최종값 ±2%(또는 ±5%) 안에 머물기 시작하는 시간 | 사실상 "다 왔다"까지의 시간 |
| 정상상태 오차 $e_{ss}$ | $t \to \infty$에서 남는 목표값과의 차이   | 끝까지 못 미치는 양      |


**트레이드오프** ⭐
- 빠르게 만들수록 많이 출렁이고, 얌전하게 만들수록 느려짐 (상승시간 ↔ 오버슈트 반비례)
- 로봇팔 부품 집을 때 5% 오버슈트 = 충돌 위험 / 드론 자세 회복 0.5초 지연 = 추락 위험
  → 응용을 어떻게 할 것인지에 따라 트레이드오프 지점이 다름
