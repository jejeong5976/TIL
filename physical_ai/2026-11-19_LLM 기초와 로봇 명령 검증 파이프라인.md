### LLM 기본 구조

- **개념**
	- LLM(Large Language Model)은 대량 텍스트에서 토큰 간 통계적 관계를 학습한 신경망
	- 토큰은 모델이 처리하는 텍스트 단위로, 단어와 일대일 대응하지 않음
	- 임베딩은 토큰 ID를 학습된 실수 벡터로 바꾼 값 (임베딩 행렬에서 해당 행을 조회함)
	- 학습은 가중치를 갱신하고, 추론은 고정된 가중치로 출력만 계산함
	- 프롬프트에 예시를 넣는 것은 입력 변경이며 가중치 갱신이 아님 ⭐

- **자기회귀 생성**
	- 앞 토큰을 조건으로 다음 토큰 분포를 계산하고, 선택한 토큰을 문맥에 붙여 같은 연산을 반복함
	- 문장 확률은 조건부 확률의 곱으로 분해됨: `P(x₁,…,xₙ) = ∏ P(xₜ | x₍<ₜ₎)`

- **Transformer와 Attention**
	- Attention으로 토큰 간 정보를 결합하는 구조
	- 입력 벡터를 선형 변환해 Q(질의), K(비교 대상), V(결합할 정보)를 만듦
	- `Attention(Q,K,V) = softmax(QKᵀ / √d_k) V`
	- 가중치가 [0.8, 0.2]이면 출력은 `0.8v₁ + 0.2v₂`

### 환각과 문맥 한계

- **개념**
	- 환각은 근거 없는 내용을 사실처럼 제시하는 현상
	- 다음 토큰 예측에는 사실 조회 과정이 없으므로, 생성 확률이 높아도 사실성과 실행 가능성은 별도로 확인해야 함 ⭐
	- 문맥은 이번 요청에서 모델에 준 지시, 예시, 문서, 관측
	- 문맥 창은 한 번에 처리 가능한 토큰 수의 한도
	- 문맥 창 안에 넣어도 정보가 누락되거나 잘못 연결될 수 있음 (근거 위치에 따라 성능이 달라짐)

- **실패 원인 분리** (모든 실패를 환각으로 부르면 해결 방법을 찾기 어려움)

| 사례 | 원인 | 검사 |
| :--- | :--- | :--- |
| 미등록 장소 B로 이동 | 근거 없는 대상 생성 | 허용 목록 |
| 예전 위치로 이동 | 오래된 관측 | 관측 시각 |
| map 좌표를 base_link로 실행 | 좌표계 혼동 | TF 변환 |

- **temperature** ⭐
	- 다음 토큰을 고를 때 확률 분포의 집중 정도를 조절하는 값 (모델의 지식이나 판단은 바뀌지 않음)
	- 동작 순서: 후보별 점수(logit) zᵢ 계산 → T로 나눔 → softmax로 확률 변환 → 샘플링
	- `pᵢ = exp(zᵢ/T) / Σ exp(zⱼ/T)`
	- 볼츠만 분포에서 온 이름 (온도가 낮으면 가장 낮은 에너지 상태에 몰리는 것과 같은 수식 구조)

| T | 1순위 확률 (logit [2,1]) | 효과 |
| :--- | :--- | :--- |
| 0.5 | 0.881 | 점수 차이가 커져 1순위에 집중함 |
| 1 | 0.731 | 모델이 계산한 원래 분포 |
| 2 | 약 0.62 | 차이가 줄어 하위 후보도 자주 뽑힘 |
| 0에 가까움 | 1에 가까움 | 거의 항상 1순위만 고름 (greedy) |

- **temperature 주의사항**
	- 낮은 T는 출력 변동만 줄일 뿐 정답 여부는 바꾸지 못함
	- 틀린 후보가 1순위면 그 오류를 더 일관되게 반복함
	- "같은 답이 나온다"와 "맞는 답이 나온다"는 따로 검증해야 함
	- T = 0이어도 서비스와 실행 환경에 따라 출력이 완전히 같다고 보장되지 않음

- **판정과 평가**
	- 판정은 실행, 확인 요청, 재관측, 보류로 구분함
	- 대상이 불명확하면 확인 요청, 미등록 목적지면 실행 보류
	- 형식 성공률 = 구조 검사 통과 수 / 전체 요청 수
	- 작업 성공률 = 실제 완료 수 / 전체 실행 과제 수 (형식 통과와 실행 적합성은 따로 평가함)

### 제로샷, 원샷, 퓨샷

- **개념**
	- 프롬프트에 넣은 예시 수로 구분함
	- 예시를 읽고 이번 출력에서 패턴을 따르는 것을 문맥 내 학습이라 함 (가중치는 그대로)
	- 예시는 출력 형식과 판단 경계를 함께 전달함
	- 정상 사례만 넣으면 보류, 확인 요청 기준이 전달되지 않음 ⭐
	- 퓨샷 구성 예: 정상 이동, 미등록 장소 보류, 모호한 대상 확인 요청

| 구분 | 예시 수 |
| :--- | :--- |
| Zero-shot | 0개 |
| One-shot | 1개 |
| Few-shot | 복수 |

- **비교 실험 원칙**
	- 예시 수와 구성만 바꾸고 모델, 평가 입력, 스키마, 생성 설정은 고정함
	- 예시가 늘면 입력 토큰, 지연, 비용도 함께 측정함
	- 시험 문장을 예시에 넣으면 데이터 누수로 성능이 과대평가됨

### CoT와 작업 분해

- **개념**
	- CoT(Chain-of-Thought)는 중간 추론 단계를 포함한 예시로 추론 성능을 높이는 프롬프팅
	- 설명이 길다고 계획이 정확한 것은 아님
	- 작업 분해는 목표를 관찰 가능한 하위 작업으로 나누고, 단계마다 전제조건, 완료조건, 실패 전이를 정의하는 것
	- 운반 예: 대상 확인 → 접근 → 집기 → 이동 → 놓기 → 결과 확인

- **실행 원칙** ⭐
	- 완료 판정은 명령 전송 기록이 아닌 센서 관측 기준 (집기 완료 근거는 파지 센서 확인, 물체 동반 이동)
	- 실패 단계 뒤의 의존 작업은 실행하지 않음
	- 집기 실패 시 이동 단계 진입을 차단하고 실패 상태를 기록함
	- 상태 기록 필드: `step_id / observation / decision / next_state`

### JSON과 JSON Schema

- **개념**

| 구분 | 정의 | 역할 |
| :--- | :--- | :--- |
| JSON | JavaScript Object Notation | 값을 표현하는 데이터 형식 |
| JSON Schema | 필드, 타입, 값의 규칙 | 구조와 값 검사 |
| API | 프로그램 간 호출 규약 | 요청과 응답 교환 |

- **JSON 문법**
	- 키와 문자열에 큰따옴표, `true`/`false`는 소문자, 주석과 마지막 쉼표는 쓸 수 없음

- **Schema 주요 키워드**
	- `required`: 반드시 포함할 키 (`properties`에만 적으면 필수가 아님) ⭐
	- `enum`: 허용 값 목록 (예: navigate, inspect, hold)
	- `additionalProperties: false`: 선언하지 않은 키를 거부함

- **검증 순서** ⭐
	- JSON 파싱 → 구조 검사 → 의미, 현장 상태 검사
	- 스키마를 통과해도 의미 오류가 있을 수 있음
	- `{"action":"navigate","target":"A","timeout_s":20}`에서 A가 미등록이면 의미 검사에서 보류함
	- 오류 코드는 단계별로 분리함 (`parse_error`, `schema_error`, `unknown_target`)

### LLM API와 로컬 LLM

- **API 처리 흐름**
	- 모델은 구조화된 명령 후보를 생성하고, 프로그램은 응답 확인과 검증, 실행 결정을 맡음
	- 응답 완료 확인 → message 해석 → JSON 검증 → 실행 후보
	- 거부, 시간 초과, 불완전 응답은 오류 처리 경로로 분기함
	- 전체 지연 = 요청 준비 + 네트워크 + 생성 + 검증 + 실행 대기

- **실패와 중복 실행 방지**
	- 타임아웃은 응답을 못 받았다는 뜻일 뿐 서버가 실행하지 않았다는 근거가 아님
	- 모델 재요청과 물리 동작 재실행을 분리하고, `command_id`로 중복 실행을 검사함
	- API 키는 환경변수로 관리하고, 모델 ID와 SDK 버전은 실험 기록에 고정함
	- Mock은 고정 응답을 돌려주는 대역으로, 파싱과 오류 처리 시험용 (Mock 성공률은 모델 성능이 아님)

- **로컬 LLM**
	- 로컬 추론은 내려받은 모델 가중치를 내 컴퓨터에서 실행하는 것
	- Ollama는 모델 다운로드, 실행, HTTP API(포트 11434)를 제공하는 도구
	- 메모리는 가중치 + KV cache + 실행 버퍼로 구성됨
	- 가중치 메모리 하한 ≈ 파라미터 수 × 비트 수 / 8 (4B × 4bit ≈ 2GB, 전체 실행 메모리와는 다름)
	- 연결 오류는 포트 11434 → 서비스 상태 → 로그 순서로 점검함

```bash
ollama pull qwen3:4b
ollama run qwen3:4b
ollama list   # 설치된 모델
ollama ps     # 실행 중인 모델
```
