### [19강] 동차 좌표 변환 4×4(SE(3))와 포즈 표현 3종

#### 최소자승법
- **과결정(overdetermined) 시스템**
	- 카메라 캘리브레이션, GPS(미지수 4개인데 위성 8개), 센서 융합처럼 측정이 미지수보다 훨씬 많은 상황
	- 노이즈 때문에 모든 방정식을 동시에 만족하는 해는 없음 → **오차가 가장 작은 해**를 택함

- **정규방정식(normal equation) 유도** ⭐
	- 잔차 `r = b - Ax`의 제곱합을 최소화하는 `x`를 구하는 문제
	- 가장 가까운 점은 **"오차가 열공간에 수직인"** 점 → 17강 정사영 원리가 그대로 식으로 이어짐

```
A^T (b - Ax) = 0
→ A^T A x = A^T b     (정규방정식)
```

	- 회귀 공식은 암기 대상이 아니라 **수직 조건에서 유도되는 결과**라는 점이 핵심


- **NumPy 구현**

```python
# 정규방정식을 직접 만들지 않고 lstsq 사용 (수치적으로 더 안정)
coef, residuals, rank, sv = np.linalg.lstsq(A, b, rcond=None)
```

| 회전행렬 | 9 | 좌표 변환에 바로 곱함 | 무겁고 오차 누적 | 좌표 변환 계산 |

### [20강] 쿼터니언과 SLERP 보간 (SLERP까지)

#### 쿼터니언

- **오일러의 회전 정리**: 어떤 3D 회전이든 하나의 축 `n`을 중심으로 각 `θ`만큼 도는 것으로 표현 가능
- 쿼터니언은 이 (회전축 n, 회전 각 θ)을 4개 숫자로 인코딩

```
q = (cos θ/2, n_x sin θ/2, n_y sin θ/2, n_z sin θ/2) = (w, x, y, z)
```

- 스칼라부 `w = cos(θ/2)` → 얼마나 도는지, 벡터부 `(x,y,z) = n sin(θ/2)` → 어느 축으로 도는지
- 회전을 나타내는 쿼터니언은 항상 **크기 1인 단위 쿼터니언**⭐ 
- 각을 `θ/2`로 쓰는 이유 ⭐ — 반각을 이용해야 **쿼터니언 곱이 회전 합성과 정확히 맞아떨어짐**


#### 쿼터니언의 장점

- **짐벌락 없음**: 축-각 표현이라 특정 각도에서 자유도가 붕괴하지 않음
- **가벼움과 안정성**: 4숫자(회전행렬은 9)로 표현, 반복 계산 후 크기를 1로 정규화만 하면 다시 유효한 회전이 됨 — 회전행렬의 Gram-Schmidt 재직교화보다 훨씬 간단
- **부드러운 보간**: 두 자세 사이를 "일정한" 각속도로 잇는 SLERP 가능


#### 쿼터니언 ↔ 회전행렬 변환

- 단위 쿼터니언 `q = (w, x, y, z)`에서 회전행렬은 다음으로 구함

```
R = [ 1-2(y²+z²)   2(xy-wz)     2(xz+wy)   ]
    [ 2(xy+wz)     1-2(x²+z²)   2(yz-wx)   ]
    [ 2(xz-wy)     2(yz+wx)     1-2(x²+y²) ]
```

- 역방향(행렬 → 쿼터니언)도 존재함
- 실습에서는 `scipy.spatial.transform.Rotation`으로 변환 가능
	- 외울 필요 X, 같은 회전 행렬을 다른 표현한 버전이라고만 이해하면 됨

#### SLERP

- 두 쿼터니언을 그냥 성분별 선형으로 섞으면(평균) 회전 속도가 일정하지 않고 중간에 크기가 1을 벗어나 왜곡됨
- **SLERP(Spherical Linear intERPolation, 구면선형보간)**: 두 자세를 구면 위 최단 호를 따라 **일정한 각속도**로 잇는 보간법

```
Slerp(q0, q1, t) = [sin((1-t)Ω)/sin Ω] q0 + [sin(tΩ)/sin Ω] q1,   t ∈ [0, 1]
```

- 여기서 `Ω`는 두 쿼터니언 사이 각 (내적 `q0 · q1 = cos Ω`)
- SLERP는 회전이 일정한 비율로 진행 → 매끄럽고 예측 가능한 움직임
	- 성분을 그냥 선형으로 섞어 정규화한 NLERP은 중간에 각속도가 불균일함

## 알게 된 것

- **최소자승법 ⭐
	- "가장 가깝다 = 오차가 수직이다" → 정규방정식 `AᵀAx = Aᵀb`
	
- **쿼터니언**
	- 그 크기는 항상 1
	- 반각(`θ/2`)을 쓰는 이유: 쿼터니언 곱셈이 회전 합성과 대응되도록 하기 위함

- **자세 표현 3종은 상황별로**
	- 오일러 각(사람이 읽을 때) / 회전행렬(좌표 변환할 때) / 쿼터니언(저장·통신·보간할 때)

- **SLERP**
	- 선형 보간(LERP)을 이용하면 단위 쿼터니언이 놓인 4차원 구 표면을 따라가지 않고, 구 안족을 가로지르는 직선 경로 - 크기가 1이 아님
	- SLERP는 구 표면을 따라가는 호(arc)의 경로를 계산하므로 크기가 항상 1로 유지되고, 회전 속도도 균일함 - 로봇이 매끄럽게 움직일 수 있음
