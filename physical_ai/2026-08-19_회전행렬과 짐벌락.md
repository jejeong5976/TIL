### [18강] 회전 행렬 2D→3D, 오일러 각과 짐벌락

- **선형변환**
	- 선형변환 조건: `T(u+v) = T(u)+T(v)`, `T(cu) = cT(u)` (선형결합 보존)
	- 임의의 벡터는 기저의 선형결합이므로, **기저 벡터가 어디로 가는지만 알면 변환 전체가 결정됨**


- **평면에서의 대표적인 선형 변환**

| 변환       | 행렬                           | 행렬식   | 특징            |
| -------- | ---------------------------- | ----- | ------------- |
| 회전 R(θ)  | `[[cosθ,-sinθ],[sinθ,cosθ]]` | 1     | 길이·각도 보존      |
| 신축       | `[[sx,0],[0,sy]]`            | sx·sy | 축별 배율         |
| 전단 (x방향) | `[[1,k],[0,1]]`              | 1     | 넓이 보존, 각도는 변형 |
| 반사 (y=x) | `[[0,1],[1,0]]`              | -1    | 방향 뒤집힘        |


**2D 회전행렬**
- `e1=(1,0) → (cosθ, sinθ)`
- `e2=(0,1) → (-sinθ, cosθ)`
- `R(30°)R(30°) = R(60°)`
	- 실제로 `R(30°)R(60°)` 행렬곱을 풀어보면 `[[0,-1],[1,0]] = R(90°)`가 나옴


**3D 축별 회전**

```
Rx(θ) = [[1,0,0],[0,cosθ,-sinθ],[0,sinθ,cosθ]]
Ry(θ) = [[cosθ,0,sinθ],[0,1,0],[-sinθ,0,cosθ]]
Rz(θ) = [[cosθ,-sinθ,0],[sinθ,cosθ,0],[0,0,1]]
```

- 각 행렬에서 **회전축에 해당하는 행 · 열이 단위행렬 모양**
	→ 그 축 방향 성분은 회전해도 값이 변하지 않기 때문
	
- **Ry만 sin 부호가 반대인 이유**⭐
    - 3D 회전은 "고정축 + 나머지 두 축의 2D 회전"으로 구성되고, 나머지 두 축의 순서는 오른손 법칙에 따른 순환 순서(x→y→z→x)를 따름
    - Rx: 회전평면 (y,z) / Rz: 회전평면 (x,y) → 표준 순서라 sin 부호 정상
    - Ry: 회전평면은 (z,x)인데 행렬 표기 관례상 (x,z) 순서로 다시 쓰면서 부호가 반전되어 "보임"
    - 근본 원인은 무한소 회전 `dr = θ(e×r)`에서 외적의 반교환성(`ea×eb = -eb×ea`)과 순환 구조


**넓이/부피 배율**
- `det[[a,b],[c,d]] = ad-bc`
- `|det A|`는 넓이/부피가 몇 배가 되는지
	- **det A = 0** → 공간이 낮은 차원으로 찌그러져 되돌릴 수 없음 (역행렬 X)


**자코비안(Jacobian)과 로봇 특이점 (singularity)** ⭐
- 2링크 로봇팔의 순기구학(끝점 위치)을 관절각 θ1, θ2로 미분한 것이 자코비안 J
	- `x = l1·cosθ1 + l2·cos(θ1+θ2)`
	- `y = l1·sinθ1 + l2·sin(θ1+θ2)`
	
- 자코비안 행렬
```
J = [ -l1·sinθ₁ - l2·sin(θ₁+θ₂), -l2·sin(θ₁+θ₂) ]
    [  l1·cosθ₁ + l2·cos(θ₁+θ₂),  l2·cos(θ₁+θ₂) ]
```
	
- 2링크 로봇팔 자코비안 `det J = l1·l2·sinθ₂
- θ2 = 0° (완전히 펴짐) 또는 180°(완전히 접힘)일 때 sinθ2 = 0 → **det J = 0 → 특이점** ⭐
	- 이 자세에서 손끝은 특정 방향으로 아무리 관절을 움직여도 갈 수 X
	 → rank 상실


 **직교행렬**
- 열벡터들이 서로 수직인 단위벡터
	- 특성 1) `QᵀQ = I`, 2) `Q⁻¹=Qᵀ` , `det Q = ±1`
- R의 i번째 열벡터와 j번째 열벡터의 합성곱은 내적 정의(성분별 곱의 합)와 동일한 식

- **Rotation Matrix의 역행렬 = 전치 행렬** ⭐
    - 대각 원소(i=j): `r_i · r_i = 1` → `|r_i| = 1` (단위벡터)
    - 비대각 원소(i≠j): `r_i · r_j = 0` → `|r_i||r_j|cosθ = 0` → θ=90° (서로 수직)
    - 결론: Rᵀ R = I는 R의 열벡터들이 정규직교기저를 이룬다는 뜻이며, 이것이 곧 회전행렬(직교행렬)의 정의가 됨


**Gram-Schmidt 재직교화**
- 실제 로봇 코드에서는 회전행렬을 반복해서 곱하다 보면 부동소수점 오차로 직교성을 잃음
	→ **Gram-Schmidt 재직교화 수행**
    1. 첫 벡터 정규화 `u1 = v1/|v1|`
    2. 두 번째 벡터에서 첫 벡터 방향 projection vector 뺀 후 정규화
	    `w2 = v2 - (v2·u1)u1`, `u2 = w2/|w2|` 
    - 적용 시점: 매 스텝이 아니라 주기적으로, 또는 `RᵀR-I` 오차가 threshold 초과 시


**회전의 합성**
- `Rz`로 돌린 뒤 `Ry`로 돌리면 `Ry·Rz` (앞에서부터 적용 순서 주의 ⭐)
- **`Ry·Rz ≠ Rz·Ry`** → 행렬곱은 교환법칙이 성립하지 않으므로 회전 순서 유의할 것!
	- 오일러 각을 주고받을 때는 "어느 축을 어떤 순서로 돌렸는가"(예: xyz, zyx, 내재적/외재적)를 반드시 함께 명시해야 함


**오일러 각과 짐벌락(Gimbal Lock)**
- 오일러 각: 회전을 세 축의 각도(roll, pitch, yaw)로 표현 → 직관적임
- **짐벌락** ⭐
	- `R = Rz(yaw)·Ry(pitch)·Rx(roll)`에서 pitch=90°이되면 roll축과 yaw축이 겹침
	- 두 각도가 독립적으로 움직이지 않고 합/차로만 결과에 영향을 줌
	- 3 자유도가 2 자유도로 붕괴 (로봇팔 특이점과 수학적으로 동일 구조)
- 해결책
	- **쿼터니언** (4개의 파라미터, 특이점 없음, ROS2 표준, 하지만 직관성 낮음)


## 알게 된 것

- 3D 회전 행렬에서 `Ry` 부호 유의할 것 - 순환 구조(x→y→z→x)로 이해하기
- `(R^T R)_ij = r_i·r_j`: 행렬곱 = 내적
- det = 0인 경우 = 로봇 특이점 → 0°  일 때 (완전히 펴짐) / 180°  일 때 (완전히 접힘)
- 오일러 각의 한계 - **짐벌락**
