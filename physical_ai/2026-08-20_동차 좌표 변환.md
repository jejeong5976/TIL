### [19강] 동차 좌표 변환 4×4(SE(3))와 포즈 표현 3종

**동차 좌표**

- 3D 점 `(x, y, z)` 뒤에 1을 붙여 `(x, y, z, 1)`로 표현
- 필요한 이유: **translation은 선형변환이 아님** (`T(0)=0`을 만족 못 함)
	→ 행렬 곱만으로 translation 표현 불가
- 차원을 하나 늘리면 **rotation(곱셈) + translation(덧셈)** 을 한 번의 행렬 곱으로 처리 가능


**마지막 성분 w** ⭐

- w=0이면 translation 항이 곱해지지 않고 rotation만 적용됨 (`(x, y, z, 0)인 경우`)
- 법선을 점처럼 `[n, 1]`로 변환하면 버그남

| w   | 의미           | 표기             |
| --- | ------------ | -------------- |
| 1   | 점 (position) | `[x, y, z, 1]` |
| 0   | 방향·속도·법선·좌표축 | `[x, y, z, 0]` |


 **4×4 동차변환행렬 SE(3)**
 
```
T = [ R   t ]     R: 3×3 rotation
    [ 0ᵀ  1 ]     t: 3×1 translation
```
	
- R: 3 x 3 matrix 
- t: 3 x 1 matrix 
- 맨 아래 행: `[0 0 0 1]`
- 점 변환: `p_A = T_AB · p_B` (B 좌표계의 점을 A 좌표계로)
	→ 강체 변환 (rigid transformation: 모양을 유지하면서 위치 이동 및 회전)
- 이런 4×4 변환의 집합을 **SE(3)**(Special Euclidean group)이라 부름


**합성**

- 좌표계 체인: `base → link → camera → object`
- `T_AC = T_AB · T_BC`
	→  `p_base = T_base_link · T_link_cam · p_cam`


 **역변환**
 
```
T⁻¹ = [ Rᵀ   -Rᵀt ]
      [ 0ᵀ    1   ]
```

- rotation은 전치 (`R⁻¹ = Rᵀ`), translation은 `-Rᵀt`로 재계산
- 유도: `T`가 점을 `Rp + t`로 보내므로 되돌릴 때 t를 먼저 빼고 `Rᵀ`를 곱함 → `Rᵀ(p-t) = Rᵀp-Rᵀt`
- Transpose를 이용하는 것이 일반 역행렬(`np.linalg.inv`)보다 빠르고 수치적으로 안정적
	→ 로봇 코드 표준


**연립 선형방정식 Ax = b**

- 동차변환처럼 구조가 특별한 경우가 아닌 일반 문제(트러스 부재의 힘, 회로 전류, 캘리브레이션 파라미터)는 Ax = b로 풀어야 함

- **해의 세 가지 경우**

| 경우 | 기하적 의미 |
|---|---|
| 유일해 | 두 직선이 한 점에서 만남 |
| 무수히 많은 해 | 두 직선이 완전히 겹침 |
| 해 없음 | 두 직선이 평행 |
- **해가 정확히 두 개인 경우는 없음** ⭐ 
	- 서로 다른 두 해 x₁, x₂가 있으면 그 사이 모든 점 `(1-t)x₁ + tx₂`도 해가 됨 (선형성)

- **rank로 해의 개수 판정하기**

| 조건 | 결과 |
|---|---|
| `rank A < rank [A\|b]` | 해 없음 |
| `rank A = rank [A\|b] = n` | 유일해 |
| `rank A = rank [A\|b] < n` | 무수히 많은 해 (자유변수 n - rank개) |


**가우스 소거법 & 피벗팅**

- **가우스 소거법**
	- 첨가행렬 `[A|b]` 에서 방정식을 위아래로 지워가며(전방 소거) 삼각형 모양을 만들고, 아래→위로 대입(후방 대입)해서 푸는 알고리즘
	
- **피벗팅**
	- 나눌 때 쓰는 대각선 수(피벗)가 너무 작으면 반올림 오차 증폭
	- 부분 피벗팅(partial pivoting): 절댓값이 가장 큰 원소를 피벗으로 올리도록 행 교환
	- `np.linalg.solve(A, b)`는 이 피벗팅을 알아서 해주기 때문에, 손으로 역행렬 구해서 곱하는 것보다 훨씬 안전함


**Cramer 공식**

- `A⁻¹ 존재 ⟺ det A ≠ 0 ⟺ rank A = n ⟺ Ax=b가 유일해를 가짐` ⭐

- Cramer 공식
	- `xⱼ = det Aⱼ / det A`
	- 손 계산·이론 유도용, 큰 문제엔 사용 X
	- 행렬식을 소행렬식 전개로 계산 시 `O(n!)`
	- 가우스 소거는 약 `2n³/3`

|     | solve       | inv @ b        |
| --- | ----------- | -------------- |
| 정확도 | 피벗팅으로 오차 억제 | 역행렬 계산에서 오차 누적 |
| 연산량 | 약 `2n³/3`   | 약 `2n³` (3배)   |
| 결론  | 항상 이쪽 사용    | 역행렬 자체가 필요할 때만 |
