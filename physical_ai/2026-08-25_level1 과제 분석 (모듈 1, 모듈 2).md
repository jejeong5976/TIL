### 모듈1 
#### 2. 원격 접속(SSH)과 센서 장치 경로 고정

- **SSH 원격 접속 실습 범위**
	- 로컬에 `openssh-server` 설치 → `systemctl status ssh`, `ss -tlnp | grep :22`로 서버 동작 확인
	- `ssh-keygen` + `ssh-copy-id`로 **비밀번호 없는 접속** 구성
	- `who`, `echo $SSH_CONNECTION`으로 **진짜 원격 세션임을 증명**하는 절차 확인
	- 헤드리스 운용 패턴: 접속 없이 단일 명령 실행(`ssh user@host 'uname -a'`), `scp` 파일 전송

- **센서 장치 경로 고정 (udev)**
	- USB 하드웨어 없이 `losetup`으로 loop 장치 2개를 만들어 라이다·IMU 역할 대체
	- `udevadm info --attribute-walk`로 장치를 구분할 속성(`loop/backing_file`) 조사
	- `/etc/udev/rules.d/`에 규칙 작성 → 붙이는 순서가 바뀌어도 **항상 같은 심볼릭 이름**을 가리키게 함
	- 규칙 키 정리 필요: `SUBSYSTEM`, `KERNEL`, `ATTR{...}`, `SYMLINK+=`, `MODE`, `GROUP` / `==`(비교) vs `=`,`+=`(할당)

| 개념 | 왜 필요한가 |
|---|---|
| 무비밀번호 SSH | 자동화·원격 온보드 컴퓨터 접속 시 매번 인증 반복 방지 |
| udev 고정 심볼릭 링크 | `/dev/ttyUSB0`처럼 붙이는 순서에 따라 이름이 바뀌는 문제 방지 → 코드에서 항상 같은 경로로 센서 접근 |
