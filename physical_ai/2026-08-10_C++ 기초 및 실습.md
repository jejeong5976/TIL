#### C++ 실행
-  터미널에 입력하여 **build** 먼저
```
g++ -Wall -Wextra -std=c++17 -o ./projects/C++_study/hello ./projects/C++_study/hello_world.cpp
```

| 옵션           | 의미             |
| ------------ | -------------- |
| `g++`        | C++ 컴파일러       |
| `-Wall`      | 주요 경고 메시지 활성화  |
| `-Wextra`    | 추가적인 경고 활성화    |
| `-std=c++17` | C++17 표준 사용    |
| `-o <파일명>`   | 출력 파일 이름 지정    |
| `<소스파일>`     | 컴파일할 C++ 소스 파일 |

-  **실행**
```
./projects/C++_study/hello 
```

## 알게 된 것

- **int vs double 나눗셈**
    - 정수형끼리 나누면 소수점이 그대로 버려짐 → 실수형으로 처리해줘야 소수점까지 정확한 결과가 나옴
    - 함수/변수 타입을 처음부터 통일해두는게 이후 코드 짤 때 훨씬 편함
    
- **`<limits>` 헤더와 버퍼 비우기**
    - `std::numeric_limits`는 `<limits>` 헤더를 include해야 사용 가능
    - `std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n')
	    - 계산기 코드 작성 시 잘못된 입력이 들어오면 buffer 무시하고 지울 때 이용 
	    - 헤더 빠뜨리지 않기 ⭐
