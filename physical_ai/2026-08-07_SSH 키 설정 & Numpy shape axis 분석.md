#### SSH Key 추가

```
SSH는 '개인키-공개키 쌍'으로 서버 인증을 처리한다.
```

| 파일           | 이름                | 역할                   |
| ------------ | ----------------- | -------------------- |
| `id_rsa`     | 개인키 (private key) | 내 컴퓨터에만 보관, 절대 공유 금지 |
| `id_rsa.pub` | 공개키 (public key)  | 접속하려는 서버/서비스에 등록     |

#### 동작 방식

1. `ssh-keygen`으로 로컬에서 키 쌍 생성
2. `id_rsa.pub` 내용을 서버(GitHub, AWS 등)에 등록 - github > settings > SSH and GPG keys
3. 접속 시 서버가 공개키로 암호화한 challenge를 보냄
4. 내 컴퓨터가 개인키로만 복호화 가능 → 본인 인증 완료

#### numpy shape와 axis — 2차원·3차원 기준

**1) 2차원 배열**

```python
a = np.array([[1, 2, 3],
              [4, 5, 6]])
a.shape   # (2, 3) → 행 2개 × 열 3개
```

|연산|결과 shape|의미|
|---|---|---|
|`a.sum(axis=0)`|`(3,)` → `[5, 7, 9]`|**행 방향(위→아래)**을 합쳐서 → **열별 합**|
|`a.sum(axis=1)`|`(2,)` → `[6, 15]`|**열 방향(좌→우)**을 합쳐서 → **행별 합**|

- `axis=0`은 **0번째 차원(행)을 붕괴**시킨다 → 남는 건 열의 개수 3개
- `axis=1`은 **1번째 차원(열)을 붕괴**시킨다 → 남는 건 행의 개수 2개

**2) 3차원 배열**

```python
b = np.array([[[1, 2], [3, 4]],
              [[5, 6], [7, 8]]])
b.shape   # (2, 2, 2) → (깊이, 행, 열)
```

|연산|결과 shape|의미|
|---|---|---|
|`b.sum(axis=0)`|`(2, 2)`|**깊이 방향**을 붕괴 → 같은 위치의 두 "면"을 겹쳐서 더함|
|`b.sum(axis=1)`|`(2, 2)`|**행 방향**을 붕괴 → 각 면 안에서 행끼리 더함|
|`b.sum(axis=2)`|`(2, 2)`|**열 방향**을 붕괴 → 각 행의 원소들을 가로로 더함|

- 핵심: **`axis=k`는 "k번째 차원을 없애고 그 방향으로 합친다"**


## 알게 된 것

-  **shape & axis**
    - `axis=k`는 "k번째 차원을 붕괴시켜 그 방향으로 집계한다"는 뜻
    - 2차원에서는 axis=0(행 방향 붕괴 → 열별 결과), axis=1 (열 방향 붕괴 → 행별 결과)로 단순하지만, 3차원 이상은 어느 차원이 붕괴되는지 shape 변화를 직접 찍어보며 확인해보기

-  **SSH 키 인증 원리**
    - 개인키(`id_rsa`)는 내 컴퓨터에만 보관하고, 공개키(`id_rsa.pub`)만 서버에 등록하는 **비대칭키 구조**
    - 서버가 공개키로 암호화한 challenge를 내 개인키로만 복호화할 수 있다는 점에서 본인 인증이 이루어짐 → 매번 비밀번호/토큰을 입력하지 않아도 되는 이유
    - 기존에 겪었던 "clone/push할 때마다 인증 실패" 문제를 근본적으로 해결하는 방법이라는 것을 이해함
