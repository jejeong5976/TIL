### 개인 공부
#### TF2
- `broadcast`: 각 노드가 `/tf`, `/tf_static`에 변환 발행
- `lookup`: 트리에서 두 프레임의 공통 조상까지 경로 찾아 중간 변환 자동 연쇄 곱셈
- `broadcast` 없으면 `lookup` 불가 → 등록 안 된 걸 확인할 수 없음

| 구분        | 동작    | 방향       |
| --------- | ----- | -------- |
| broadcast | 변환 등록 | 노드 → TF2 |
| lookup    | 변환 조회 | TF2 → 노드 |

- broadcaster/lookup 코드는 `tf2_ros::TransformBroadcaster`, `tf2_ros::Buffer` + `lookupTransform()` 패턴으로 구현


#### 1차 시스템 정착시간 계산

**1차 시스템의 미분방정식**
 
$$\tau \dot{y}(t) + y(t) = y_{final}$$
 
$$y(t) = y_{final}\left(1 - e^{-t/\tau}\right)$$
 
$$y(\tau) = y_{final}\left(1 - e^{-1}\right) \approx 0.632\, y_{final}$$

| t   | 도달률   |
| --- | ----- |
| τ   | 63.2% |
| 2τ  | 86.5% |
| 3τ  | 95.0% |
| 5τ  | 99.3% |
- 시정수 τ가 2초일 때의 정착 시간( 최종값 ±2% (또는 ±5%) 안에 머물기 시작하는 시간
  → t = 6초 (=3τ)


#### 오버슈트
- 오버슈트 식
 
$$\text{Overshoot}(\%) = \frac{y_{peak} - y_{ss}}{y_{ss}} \times 100$$
- 감쇠비 ζ와의 관계:
 
$$\text{Overshoot}(\%) = e^{-\zeta\pi / \sqrt{1-\zeta^2}} \times 100$$
 
	- 31% 오버슈트 ≈ (ζ ≈ 0.35) - 오버슈트 큰 편임
	- 일반 권장 ζ = 0.6-0.8 (오버슈트 1-10%)
- 오버슈트는 상승 시간과 반비례 관계  ⭐


#### 부하(무게중심) 변화 시 PID 대응
- 물건 파지 → 관성 증가, 중력토크 변화 → 고정 게인은 더 이상 최적 아님 (plant variation이라고 함)
- 대응법: gain scheduling / feedforward 중력보상(URDF 질량·관성 + 역동역학) / 적응제어(MRAC) / 강인제어(H∞, SMC) / 외란관측기(DOB) 등
- 실무 조합: 중력보상 + 그리퍼 무게추정 + 무게구간별 게인스케줄링

## 알게 된 것
